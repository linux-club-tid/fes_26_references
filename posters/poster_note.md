- Terminal
    - Hackerの黒い画面を解き明かす
    - 文字だけでどうやって操作をするのか
        - そもそもコンピュータの操作はコマンドによって行える
            - e.g. `mkdir :: make dir(フォルダを作成して)`
            - マイクラのコマンドと同様の目的
        - でもエクスプローラーで右クリックしたり、Ctrl + Shift + nをすれば作れるじゃん?
        => いくつかの大きいメリットがある
            - まず自動化のしやすさ
                - コマンドはscriptというかたちで一つのファイルにまとめて実行ができる
                    - 定型的な作業は機械で自動化ができて便利
                - 同じコマンドは(多くの場合)同じ挙動なので*操作の*コピペが可能
            - コマンドの組み合わせによる柔軟な処理
                - コマンドの結果を次のコマンドに渡すことでリレーのような処理が可能
                - 例えば以下のコマンドがある
                    - `ps` :: 現在動作中のプログラムを確認するコマンド `ps aux`とするとシステム全体で稼働するプログラムを一覧できる
                    - `rg` :: 入力された内容を検索する `rg chrome`
                    - // stdin, outについてはあとから
                - これらを組み合わせると`ps aux | rg chrome`
                    - このコマンドはシステム全体で動くプログラムにchromeが含まれているかを確認できる
                    - 仕組み
                        1. `ps aux`でプログラム一覧を
                        1. pipe `|`は`ps aux`の結果を次の`rg chrome`というコマンドに流す
                        1. `rg chrome`は`ps aux`の結果を受け取ってそこを対象に`chrome`が含まれる場所を探す
                    - pipeの便利なところは上記の動作を組み合わせによって実現するため、簡単に修正や改善ができる
            => このCLIでは単一の機能を持ったコマンドをうまく組み合わせることで大きな仕事をするという考え方がある
    - ちなみにTUIというものもある
        - 現代ではコマンドだけでなく文字だけでグラフィカルな操作を行うためのツールもある
        - e.g. nvim, lazygit, etc...
