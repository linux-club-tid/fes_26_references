# shell体験「迷子のペンギン Tux を探せ！」

学園祭スタッフ向けの運営資料です。参加者は左右に分割された画面を使い、
`ls`、`cat`、`grep` などの基本的なコマンドを体験します。

- 基本コース（3問）: 5～8分
- 発展コース（全5問）: 10～15分
- 画面左: 問題とヒント
- 画面右: 参加者が操作するbash

問題の答えを含むため、参加者にはこのディレクトリを見せないでください。

## 当日までに確認すること

次の環境を、sudo権限を持たない体験専用ユーザーで用意します。

- LinuxまたはLinux VM
- Python 3.10以降
- bash
- tmux
- 日本語を表示できる端末と等幅フォント

体験環境には個人ファイルや秘密情報を置かないでください。VMを使う場合は、
ネットワーク、共有フォルダー、共有クリップボード、ドラッグ＆ドロップを無効にします。
WSL2ではWindowsドライブの自動マウントとWindows interopも無効にします。

## 開場前の動作確認

このディレクトリへ移動し、体験を起動します。

```sh
cd trial_tools/shells
./new.py
```

次の点を確認してください。

1. 左側に最初の問題、右側に `trial$` が表示される。
2. 右側のpaneが選択され、キーボード入力できる。
3. スタッフ自身で基本3問と発展2問を最後まで進められる。
4. `Ctrl+B` を押して離し、`Shift+R`、`y` の順で終了できる。
5. `./new.py` で起動し直すと、最初の問題へ戻る。

画面は最大化し、少し離れた場所からでも読める文字サイズに調整してください。

## 参加者への案内

最初に、次の内容だけを案内します。

> 右側の黒い画面は、文字でコンピューターにお願いする場所です。
> 左側の問題を見ながら操作します。間違えても体験専用なので大丈夫です。
> まず `ls` と入力してEnterを押してください。

- `trial$` 自体は入力せず、その右側へ入力する。
- Tabでファイル名を補完できる。
- 答えが分かったら `ans 答え` で送信する。

参加者が考える時間を取り、詰まったときは左側に表示されるヒントから順に案内します。
想定と違うコマンドでも、答えへ到達できれば問題ありません。

3問目の後はコース選択が表示されます。混雑時や参加者が疲れている場合は
`ans finish`、続けられる場合は `ans next` を入力してもらいます。

## 次の参加者へ交代する

各回が終わったら、次の手順で新しい環境を用意します。

1. `Ctrl+B` を押して離す。
2. `Shift+R` を押す。
3. 確認表示で `y` を押す。
4. 元の端末で `./new.py` を実行する。
5. 最初の問題が表示され、右側のpaneが選択されていることを確認する。

各回は新しい作業ディレクトリで始まるため、前の参加者による変更は引き継がれません。
過去の作業ディレクトリは閉場後に管理者が一括削除します。スタッフ自身の当日判断で、上位階層や関係ないディレクトリを削除しないでください。

## 困ったとき

| 状況 | 対応 |
| --- | --- |
| 入力した処理が止まらない | `Ctrl+C` を1回押す |
| 文字が大量に流れた | `Ctrl+C` の後に `clear` を実行する |
| `command not found` | スペルと半角英字を確認する |
| `No such file or directory` | `ls` で名前を確認し、Tab補完を使う |
| 左側の問題が進まない | 答え送信後に数秒待ち、直らなければセッションを作り直す |
| paneやshellを閉じた | その回を終了し、`./new.py` で作り直す |
| `tmuxが見つかりません` | 予備PCへ案内し、環境担当者へ連絡する |

参加者の前では `sudo` を使った復旧や設定変更を行わず、原因調査が長引く場合は
予備PCへ案内してください。
