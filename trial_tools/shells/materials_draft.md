# CLI体験 教材原案

## ねらい

Linuxをほとんど知らない参加者に、次の3点を体験してもらう。

- コマンドでファイルの内容を調べられる
- 大量の文章から必要な行だけを取り出せる
- 小さなコマンドをパイプで組み合わせられる

コマンドの暗記や正確な用語説明は目的にしない。所要時間は基本問題で5～8分、追加問題を含めて10～15分程度を想定する。

## 題材

「迷子のペンギンTuxを目撃記録から探す」という短いストーリーにする。Linuxとの関連を持たせつつ、ログ解析などの知識がなくても内容を理解できる。

使用するファイル名は入力しやすいASCIIに統一する。

```text
welcome.txt     操作説明と最初の手掛かり
members.txt     動物と担当の一覧
sightings.txt   Tuxの目撃記録
```

## 進行

### 0. 導入

左paneに次の説明を表示する。

> 右側の黒い画面は、文字でコンピューターにお願いをする場所です。  
> 間違えても体験用の環境なので大丈夫です。まずは `$` の右に `ls` と入力して Enter を押してください。

スタッフは、`$`自体は入力しないことと、Tab補完を最初に説明する。

### 1. ファイルを見つける：`ls`

課題文：

> この場所にあるファイルを一覧表示してください。

想定コマンド：

```sh
ls
```

成功条件：`welcome.txt`、`members.txt`、`sightings.txt`が表示される。

### 2. ファイルを読む：`cat`

課題文：

> `welcome.txt`の内容を表示して、探すペンギンの名前を確認してください。

ヒント1：

> ファイル全体を表示するコマンドは`cat`です。

ヒント2：

```sh
cat welcome.txt
```

回答：`Tux`

### 3. 必要な行を探す：`grep`

課題文：

> `members.txt`から、名前に`Tux`を含む行だけを表示してください。Tuxの担当は何でしょう？

ヒント1：

> `grep 検索する文字 ファイル名`の順に入力します。

ヒント2：

```sh
grep Tux members.txt
```

回答：`guide`

ここまでを基本コースとする。混雑時や低年齢の参加者は、ここで完了してもよい。

### 4. 行番号も表示する：`grep -n`

課題文：

> `sightings.txt`から`Tux`の目撃記録を、行番号付きで表示してください。最後に目撃された場所はどこでしょう？

ヒント：

```sh
grep -n Tux sightings.txt
```

回答：`PC Room`

### 5. コマンドを組み合わせる：`|`と`wc -l`

課題文：

> `Tux`を含む目撃記録は全部で何件ありますか？`grep`の結果を`wc -l`へ渡して数えてみましょう。

ヒント1：

> `|`は、左のコマンドの結果を右のコマンドへ渡します。

ヒント2：

```sh
grep Tux sightings.txt | wc -l
```

回答：`4`

締めの説明：

> 今使った`cat`、`grep`、`wc`は、それぞれ小さな仕事をする道具です。LinuxのCLIでは、道具を`|`でつないで複雑な仕事を組み立てられます。

## 判定方法

入力したコマンド自体は採点せず、参加者が見つけた答えを`guide.py`へ入力して判定する。同じ結果へ到達する別解を許容する。

回答では、英字の大文字・小文字、前後の空白、全角・半角の違いを可能な範囲で吸収する。間違いが続いた場合は、失敗表示ではなく段階的にヒントを出す。

## 表示上の注意

- 一度に表示する説明は4～6行程度にする
- コマンドとファイル名は色または太字で区別する
- 「正解・不正解」より「見つかった・もう一度探す」という表現を使う
- `Ctrl+C`、Tab補完、上下キーによる履歴を画面下部に常時表示する
- コマンドと回答はASCIIだけで入力できるようにする

- 基本コース完了時に修了画面や小さな記念表示を出すか
