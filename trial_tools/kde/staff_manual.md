# KDE体験 スタッフマニュアル

## 1. 体験の目的と所要時間

参加者がKDE Plasmaを自由に触り、「Linuxでは見た目や操作方法まで自分好みに変えられる」と感じることを目標にする。設定項目の暗記や完成度の採点は行わない。

- 基本コース: 約10分
- 追加チャレンジ: 5～10分
- 対象: マウスのクリック、右クリック、ドラッグができる人
- スタッフ配置: 体験PC 1～2台につき1人を目安とする

基本コースでは、壁紙とテーマの変更、パネルの調整、ウィジェットの配置を行う。時間と本人の興味に応じて画面効果も試してもらう。すべてを終わらせることより、参加者が気に入った項目を自分で選ぶことを優先する。

## 2. 当日までの準備

### 必要な環境

- KDE Plasma 6を日本語で利用できるLinux VM
- VirtualBoxを実行できる体験PC
- sudo権限を持たない体験専用ユーザー
- 参加者向けマニュアル `trial_tools/kde/manual.pdf`
- 復元確認済みの初期スナップショット
- すぐ交代できる予備PCまたは予備VM

VMではネットワーク、共有フォルダー、共有クリップボード、ドラッグ＆ドロップ、USB機器の自動接続を無効にする。ホストPCやVMに個人ファイル、保存済みアカウント、秘密情報を置かない。体験専用ユーザーには管理者権限を与えない。

初期スナップショットは、次の状態を確認してから作成する。

1. 体験専用ユーザーで自動ログインまたはログインできる。
2. 表示言語、キーボード、日時が日本向けになっている。
3. 画面解像度と拡大率が体験PCに合っている。
4. 壁紙、グローバルテーマ、ウィジェット、画面効果の候補があらかじめ入っている。
5. パネルが表示され、アプリケーションメニューとシステム設定を開ける。
6. 参加者向けマニュアルがすぐ読める位置に用意されている。
7. VMを初期スナップショットへ復元し、同じ状態へ戻ることを確認している。

会場で使うVM名とスナップショット名は、スタッフ全員が見える運営メモへ記入する。復元先を推測で選ばない。

### 開場前チェック

各PCで次を確認する。

1. ホストPCを電源へ接続し、スリープを無効にする。
2. VMを初期スナップショットへ復元して起動する。
3. KDE Plasmaのデスクトップが日本語で表示されることを確認する。
4. マウスの右クリック、ドラッグ、キーボード入力が動作することを確認する。
5. システム設定を開き、「色とテーマ」と「デスクトップ効果」を表示できることを確認する。
6. デスクトップとパネルの編集モードを開き、閉じられることを確認する。
7. ウィジェットを1つ追加して削除する。
8. 参加者向けマニュアルの手順を最初から最後まで一度試す。
9. VMをもう一度初期スナップショットへ復元する。

ネットワークへ接続できないこと、ホストとのファイル共有やクリップボード共有ができないことも確認する。

## 3. 参加者への案内

着席したら、次のように説明する。

> この体験では、Linuxのデスクトップを自分好みに作り変えます。壁紙、色、画面下のパネルなどを自由に変えてみてください。体験専用なので失敗しても大丈夫です。困ったときはすぐ元に戻せるので、気軽に声をかけてください。

続けて、次のルールだけを伝える。

- 個人情報を入力しない。
- 自分のアカウントへログインしない。
- ファイルを削除しない。
- 新しいテーマ、ウィジェット、ソフトウェアをダウンロードしない。
- 設定のためにパスワードを求められたら、入力せずスタッフを呼ぶ。

最初は「デスクトップの何もない場所を右クリックしてみましょう」と案内する。その後は参加者向けマニュアルを見てもらい、スタッフが操作を先取りしすぎない。完成例を正解として押しつけず、「どんな色が好きですか」「パネルはどこにあると使いやすそうですか」のように選択を促す。

## 4. 体験の進め方

| 段階 | 参加者が行うこと | スタッフが確認すること |
| --- | --- | --- |
| 導入 | デスクトップを右クリックする | メニューが開き、操作できる |
| 1A | 壁紙を選んで適用する | 文字やアイコンが見える壁紙になっている |
| 1B | グローバルテーマまたは配色を変える | 適用確認を理解し、必要ならレイアウト変更を外す |
| 2 | パネルの位置、太さ、長さなどを変える | パネルを見失わず、編集モードを終了できる |
| 3A | ウィジェットを追加して配置する | 削除方法も必要に応じて案内する |
| 3B | 画面効果を有効にして試す | 動作が重くなっていない |
| 完成 | 気に入った点をスタッフへ見せる | 参加者の工夫を短く聞き、体験を締める |

混雑時は壁紙、テーマ、パネルまでを基本コースとして区切ってよい。参加者が1つの項目を気に入って長く試している場合も、無理に次へ進ませない。

### 案内する設定経路

- 壁紙: デスクトップを右クリック →「デスクトップと壁紙を設定…」
- テーマと配色: アプリケーションメニュー → システム設定 → 色とテーマ
- パネル: パネルの何もない場所を右クリック →「パネル設定を表示」
- ウィジェット: パネルを右クリック →「パネル設定を表示」→「ウィジェットを追加」
- 画面効果: システム設定 → ウィンドウの管理 → デスクトップ効果

表示名が少し異なる場合は、システム設定の検索欄で「壁紙」「色」「効果」などを検索する。

### 声かけの順序

参加者が止まったときは、次の順で支援する。

1. 「今は何を変えたいですか」と目的を確認する。
2. マニュアルの該当箇所や画面上の項目を指し示す。
3. クリック、右クリック、ドラッグのうち必要な操作を1つだけ伝える。
4. それでも難しい場合は、参加者の了承を得てスタッフが一度だけ操作を実演する。

スタッフが操作を引き取る場合も、何を変更するか説明し、最後の選択や「適用」はできるだけ参加者に行ってもらう。

## 5. サポートの基準

### 操作に慣れていない参加者

- 一度に案内する操作は1つにする。
- 右クリックする場所やドラッグ先を指で示す。
- ダブルクリックとシングルクリックを混同していたら、必要な方だけを伝える。
- 文字が小さければ、体験を続ける前にスタッフが表示倍率を調整する。
- パネルやウィジェットの細かな調整は省略してよい。

### 早く終わった参加者

次から興味のあるものを1つ案内する。

- 明るい配色と暗い配色で壁紙の見え方を比べる。
- パネルを上下左右へ動かし、使いやすさを比べる。
- ウィンドウを開いて、パネルの自動非表示を試す。
- 「揺れるウィンドウ」「マジックランプ」「概要」などの画面効果を試す。
- `Meta + W`、`Alt + Tab`、`Meta + 矢印`でウィンドウ操作を試す。

ソフトウェアや追加テーマのインストール、オンラインアカウントの設定、教材にないシステム管理操作は案内しない。

### 体験の締め

完成したら、参加者に気に入った点を1つ聞く。

> 壁紙だけでなく、パネルの場所やウィンドウの動きまで変えられました。Linuxでは、この画面部分も自分に合うものを選び、自由に調整できます。

作品を撮影する場合は、参加者本人や持ち物が写り込まないようにし、撮影と利用目的について本人の同意を得る。

## 6. 次の参加者への初期化

参加者ごとに必ず初期スナップショットへ戻す。KDEの設定を手作業で戻す方法は、変更の見落としが起きるため通常の初期化には使わない。

1. 参加者が終了したことを確認する。
2. 開いている設定画面やアプリを閉じる。
3. KDEから通常どおりシャットダウンし、VMが完全に停止するまで待つ。
4. VirtualBoxで対象のVM名を確認する。
5. 事前に指定された初期スナップショットへ復元する。
6. VMを起動し、デスクトップ、パネル、壁紙が初期状態であることを確認する。
7. 参加者向けマニュアルを最初のページへ戻し、次の人を案内する。

混雑時も、前の参加者の設定を残したまま次の体験を始めない。復元に時間がかかる場合は予備VMまたは予備PCへ案内する。

開催中に新しいスナップショットを作成、削除、上書きしない。保存する必要がある作品があっても、運営責任者の判断なしにVMやホストへ書き出さない。

## 7. トラブル対応

### パネルが見つからない

1. 画面の上下左右すべての端へマウスカーソルを近づけ、自動非表示になっていないか確認する。
2. `Esc`を数回押して編集モードやメニューを閉じる。
3. デスクトップを右クリックし、編集モードからパネルの状態を確認する。
4. 誤って削除され、短時間で戻せない場合はその回を終了してスナップショットから復元する。

参加者の操作を責めず、「パネルまで作り変えられることが分かりましたね。すぐ戻せます」と案内する。

### ウィジェットを消せない

編集モードを開き、対象のウィジェットを選んで削除する。右クリックメニューから削除できる場合もある。操作箇所が分からなければ、無理に直さず体験終了後にスナップショットへ戻す。

### 画面表示が崩れた、文字が読めない

- グローバルテーマを変えた直後なら、別の標準テーマまたは配色へ変更する。
- パネルやウィンドウが操作できるなら、参加者の体験を止めず別の項目へ案内する。
- 操作が難しい状態なら、VMを通常終了して復元する。

### 画面効果で動作が重い、表示が乱れる

直前に有効にした効果をオフにして「適用」を押す。改善しなければVMを終了し、別のPCへ案内してから復元する。ホストPCを強制終了する前に運営責任者へ連絡する。

### 設定変更でパスワードを求められた

パスワードは入力しない。その操作をキャンセルし、体験範囲外であることを伝える。参加者へ管理者パスワードを教えない。

### VMが固まった、起動しない

1. 30秒ほど待ち、マウスやキーボードへの反応を確認する。
2. VirtualBoxの状態と画面のエラーを記録する。
3. 参加者を予備PCへ案内する。
4. 通常終了できる場合は終了し、初期スナップショットへ復元する。
5. 強制停止が必要な場合は、運営責任者の確認を得る。

参加者の前で長時間の原因調査、管理者権限での修復、パッケージ更新は行わない。

## 8. スタッフ用クイックリファレンス

| 状況 | 対応 |
| --- | --- |
| 設定項目が見つからない | システム設定の検索欄でキーワード検索 |
| メニューや編集を閉じたい | `Esc` |
| アプリケーションメニューを開く | `Meta` |
| ウィンドウ一覧を表示 | `Meta + W` |
| ウィンドウを切り替える | `Alt + Tab` |
| ウィンドウを画面半分へ配置 | `Meta + 矢印` |
| アプリや設定を検索する | `Alt + F2` |
| パネルが見えない | 画面の四辺へカーソルを動かす |
| 状態を完全に戻す | VM停止 → 指定スナップショットへ復元 → 再起動 |

この体験では、設定をきれいに仕上げることより、参加者が自分で選び、変化を楽しめたことを大切にする。
